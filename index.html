A sync code carries this account, its play history and its osu! link to another browser or device.

osu! does not let web pages sign in or submit plays: its API sends no CORS headers and OAuth needs a client secret. This account lives in your browser, and the sync code is how it travels. Saved maps can still be downloaded as .osz for osu!.
